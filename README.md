# Парсер Savent.ua -> Prom.ua (YML XML) с автоматизацией через GitHub Actions

Автоматический парсер товаров с сайта поставщика [savent.ua](https://savent.ua/) в формат YML XML, готовый для импорта в **Prom.ua**.

---

## 🚀 Возможности
- **Сбор всех товаров**: парсит все карточки товаров из официальных sitemap.
- **Двуязычность**: собирает украинские и русские названия (
ame_ua, 
ame), а также полные описания (description_ua, description).
- **Все фотографии**: сохраняет полный список полноразмерных фото товара (не только первое).
- **Характеристики**: извлекает все параметры (вес, страна, применение и т.д.) в теги <param name=...>.
- **Цены и наличие**: актуальная цена в грн (price) и статус наличия (vailable=true / false).
- **Автообновление**: каждые 4 часа через GitHub Actions (по расписанию cron).

---

## 📁 Структура проекта
- parser.py — основной скрипт парсинга и формирования фида.
- eed.xml — сгенерированный файл фида для Prom.ua.
- equirements.txt — необходимые библиотеки Python (equests, eautifulsoup4, lxml).
- .github/workflows/parse.yml — конфигурация автозапуска GitHub Actions каждые 4 часа.

## 🛠 Пошаговая инструкция: Перенос на GitHub

### Шаг 1. Создание репозитория на GitHub
1. Перейдите на [github.com](https://github.com/) и создайте новый **публичный (Public)** репозиторий (например, savent-parser).
2. Не добавляйте автоматически README, .gitignore или лицензию (они уже есть в проекте).

### Шаг 2. Отправка кода в репозиторий
Откройте терминал (PowerShell или командную строку) в папке проекта и выполните команды:

`ash
git init
git add .
git commit -m Initial commit: Savent parser and GitHub Actions
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/savent-parser.git
git push -u origin main
`
*(Замените ВАШ_ЛОГИН_GITHUB на ваш логин на GitHub)*.

---

### Шаг 3. Включение прав записи для GitHub Actions
Чтобы GitHub Actions мог обновлять файл eed.xml в репозитории:
1. В вашем репозитории на GitHub перейдите во вкладку **Settings** (Настройки).
2. В левом меню выберите **Actions** -> **General**.
3. Прокрутите вниз до раздела **Workflow permissions**.
4. Выберите пункт **Read and write permissions** (Права на чтение и запись).
5. Нажмите кнопку **Save**.

---

### Шаг 4. Проверка и ручной запуск
1. Перейдите во вкладку **Actions** в вашем репозитории.
2. Слева выберите воркфлоу **Update Prom Feed**.
3. Справа нажмите кнопку **Run workflow** -> **Run workflow**.
4. Через 20–30 секунд процесс завершится зеленым флажком, а файл eed.xml в репозитории обновится!
5. Далее парсер будет запускаться **автоматически каждые 4 часа**.

---

### Шаг 5. Подключение ссылки в кабинете Prom.ua

Для импорта товаров в Prom.ua вам нужна прямая ссылка на сырой файл eed.xml:

`
https://raw.githubusercontent.com/ВАШ_ЛОГИН_GITHUB/savent-parser/main/feed.xml
`

В кабинете Prom.ua:
1. Перейдите в **Товары и услуги** -> **Импорт**.
2. Вставьте указанную выше ссылку в поле ссылки на XML/YML файл.
3. Настройте периодичность импорта в Prom.ua.
